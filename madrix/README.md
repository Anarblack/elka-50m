# Ёлка 50 м → MADRIX 5

Координаты всех пикселей ёлки, адреса DMX и эффекты для MADRIX 5.
Координаты берутся из того же генератора, что и 3D-модель (https://anarblack.github.io/elka-50m/),
поэтому пиксель № N в MADRIX — это тот же пиксель, что в модели.

**Параметры экспорта по умолчанию:** высота 50 м со звездой, Ø нижнего яруса 18 м, шаг пикселя 15 см,
пиксели на внешних 3 м ветки.

| | |
|---|---|
| Пикселей | 55 398 (ёлка 54 994 + звезда 404) |
| Веток / ярусов | 923 / 32 |
| Портов по 680 пикселей | 86 |
| DMX-юниверсов | 342 (номера 1…343) |
| Контроллеров по 16 портов | 6 |

## Файлы

| Файл | Зачем |
|---|---|
| `elka50_madrix_2d_cylinder.csv` | **Основной патч для MADRIX.** Ёлка развёрнута в плоскость 240 × 200: X — угол вокруг ёлки (1 колонка ≈ 1,5°, фронт в центре, шов сзади), Y — высота (1 = верхушка, 1 ряд = 25 см). На нём работают все штатные эффекты, текст и видео. |
| `elka50_madrix_3d.csv` | Объёмный патч: вокселы по 30 см, сетка 58 × 167 × 59. Для объёмных эффектов (Explosions, Shapes, Metaballs) — сферы и волны идут сквозь крону. |
| `elka50_pixels_meters.csv` | Все пиксели в метрах (x, y вверх, z) + ярус, ветка, контроллер, порт, юниверс, канал. Для монтажников и любого другого софта. |
| `elka50_ports.csv` | Таблица подключения: контроллер → порт → юниверсы → какие ярусы и ветки. |
| `effects/*.mas` | 6 эффектов MAS Script под 2D-патч. |
| `export.mjs` | Пересобрать всё с другими размерами. |

В MADRIX загружается **один** из двух патчей: 2D или 3D. Если нужны текст, видео и большинство эффектов — берите 2D.
Для «салюта сквозь ёлку» и объёмных фигур — 3D.

## Импорт в MADRIX 5

Нужен Windows-ПК с MADRIX 5. Без ключа MADRIX KEY программа работает в демо-режиме:
патч и превью доступны, выключен только вывод на контроллеры.

1. **Patch Editor** → начните с пустого патча.
2. `File > Import Fixture List…` → выберите `elka50_madrix_2d_cylinder.csv` (или `_3d.csv`).
3. **CSV Import Settings:** Use Header Line — **1**, Field Separator — **Comma**, Text Delimiter — **None**,
   кодировка UTF-8. Проверьте Data Preview: должно быть 8 колонок.
4. **Fixture List Import Settings** — назначьте колонки (двойной клик по строке Assignment):
   `Product → Product`, `Display Name → Display Name`, `Fixture ID → Fixture ID`,
   `Position X/Y/Z → Position X/Y/Z`, `DMX Universe → DMX Universe`, `DMX Channel → DMX Channel`.
   Index Convention — **1-Based** (каналы в файле: 1, 4, 7 … 508).
5. **Assigned Products:** для `Pixel RGB 12mm` выберите `!generic RGB Light 1 pixel`, протокол DMX.
6. Position Settings: Scale — **1** по всем осям, стартовая позиция — как в файле.
7. **Matrix Settings → Match Voxel Map Area.**
8. Проверка: 55 398 приборов; размер 240 × 200 × 1 для 2D или 58 × 167 × 59 для 3D; юниверсы 1…343.
   Импорт такого количества приборов может занять несколько минут.

Несколько пикселей могут попасть в одну ячейку сетки (ветки стоят в глубину кроны).
Они светятся одним цветом — так и задумано, по отдельности их с площади не различить.

### Подключение (Output)
Порт N контроллера получает юниверсы `4·(N−1)+1 … 4·N` по сквозной нумерации — смотрите `elka50_ports.csv`.
Ветка целиком сидит в одном порту. Звезда — отдельный порт (последний).

**Порядок пикселей в ветке** (так пронумерованы адреса): сначала боковые веточки — от ствола к кончику,
каждая от основания наружу, затем внешняя часть главной ветки к кончику. Если монтажники поведут нить иначе,
скажите схему — пересоберу порядок в экспорте, чтобы не перепатчивать руками.

## Эффекты

### Готовые скрипты (MAS Script Effect, для 2D-патча)
| Файл | Эффект |
|---|---|
| `elka_01_warm_twinkle.mas` | Тёплое мерцание с редкими белыми вспышками |
| `elka_02_spirals.mas` | Красно-золотые спиральные ленты, вращаются |
| `elka_03_rainbow.mas` | Радуга снизу вверх с закруткой |
| `elka_04_snowfall.mas` | Снегопад: белые штрихи бегут вниз по синему |
| `elka_05_star_wave.mas` | Цветные кольца идут вниз от звезды |
| `elka_06_fireworks.mas` | Салют: цветные вспышки расходятся по поверхности |

Как запустить: добавьте в слой эффект **MAS Script** → откройте редактор скрипта → вставьте текст файла →
**Compile** → **Start**. В начале каждого файла есть `SPEED` (темп) и `BRIGHT` (яркость).

`effects/preview.png` — кадры этих скриптов на развёртке 240 × 200 (верхний ряд — 2,5 с, нижний — 6 с).
Они получены прогоном тех же скриптов через `effects/preview.mjs`: грубый перевод в JavaScript
и заглушки функций MADRIX.

> Скрипты написаны по документации MADRIX Script и **ещё не компилировались в самом MADRIX**.
> Если компилятор ругнётся — пришлите текст ошибки, поправлю. Если FPS проседает — уменьшите
> матрицу в экспорте (`--cols 180 --rows 160`) или используйте штатные эффекты ниже.

### Штатные эффекты MADRIX (рецепты под 2D-патч)
- **Тёплое мерцание** — SCE Color (тёплый белый ≈ #FF9A42) + сверху слой SCE Noise (белый, редкий),
  режим смешивания Add/Lighten.
- **Спирали** — SCE Color Scroll (красный/золотой полосами), движение влево/вправо;
  в Mapping слоя поверните его на 20–30°. Получаются косые ленты, то есть спираль на ёлке.
- **Радуга** — SCE Color Scroll с радужной палитрой, направление вверх.
- **Снегопад** — SCE Drops (белый, вниз) или SCE Starfield.
- **Волна от звезды** — SCE Color Scroll вниз с чередованием цветных и тёмных полос.
- **Салют** — SCE Explosions. В 2D-патче вспышки у верхушки вытягиваются по ширине
  (там окружность ёлки маленькая); в 3D-патче это настоящие сферы.
- **Надпись «2027»** — SCE Ticker / Scrolling Text, движение влево, высота шрифта ≈ 50 рядов (заглавные ≈ 9 м),
  по вертикали — ряды 105…168 (это 8–24 м от земли). На ёлке читаются только крупные знаки (≈ 9 м):
  по высоте пиксели идут ярусами через ~1,4 м.
- **Видео** — SCE Video, ролик под кадр 240 × 200. Центр кадра — фронт ёлки, левый и правый края сходятся сзади.

## Лицензия
Для вывода на контроллеры нужен MADRIX 5 KEY не меньше чем на **342 DMX-юниверса** —
уточните редакцию у дилера. Демо-режим годится, чтобы всё подготовить и показать в превью.

## Пересобрать с другими размерами
```bash
node madrix/export.mjs --D 20 --pitch 0.1 --zone 3.5 --voxel 0.25 --cols 300 --rows 200 --front 51.5
```
`--front` — азимут главной точки обзора в градусах: эта сторона будет в центре 2D-развёртки
и спереди в 3D (по умолчанию — ракурс, с которого открывается модель).
